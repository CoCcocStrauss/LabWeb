# 仅正文盲评与两道比较题（2026-11-26，待发布）

依据用户最新反馈，覆盖上一版“盲评保留头像昵称”和“同卡两个选择按钮”的呈现方式。

- 四帖盲评只渲染正文，完全移除作者组件及头像/昵称；认证、身份标签和互动状态继续隐藏。桌面左右两道评分、手机上下评分与手动下一条不变。
- 观点对比改为同一页上下两道单选题：第一题最符合，第二题最不符合。每题下方列出正文选项，桌面双列、手机单列；中性内容编号在两题间保持一致。
- 第一题全部候选，第二题动态过滤第一题所选帖子。先完成第一题才启用第二题；改选第一题时，如与第二题旧答案冲突则清空第二题，原第一题选项按原顺序回到第二题。
- 两题均有效才启用继续，不自动切页。候选抽样、seed、来源、参考立场及posttest.bestWorstComparison数据格式不变；刷新保留候选顺序、两项答案和首次呈现时间。无需SQL或RPC调整。

本机验证：54项测试和生产构建通过。真实Chromium桌面1280×720育儿补贴与手机390×844 AI医疗完整流程通过；每张盲评卡的可见文字逐字等于正文，无作者或图片；比较页验证5条第一题选项、4条第二题选项、排除与返回、改选清空冲突、真实刷新恢复及最终隔离库保存。0/1条转发超时的3条候选边界同样通过。
