# 双卡行组与展开位置锁定（2026-11-26，已发布）

- 半区不再使用dense网格。每两张卡片放入独立dual-zone-pair，每组自行排版，后续组不能往前补位。单张展开卡在本组第一行占满两列，另一张到本组第二行；两张都展开时保留较早展开者的先后位置，不自动收起任何卡片。
- 阅读页主滚动容器与教程预览区均设置overflow-anchor:none，保留滚动条稳定占位。
- 点击前记录未裁剪的卡片视口top（包括顶部部分被遮住的情况）。DualZoneFeed在useLayoutEffect内、FLIP动画启动前同步通知布局，偏差超过4px时直接对实际滚动容器scrollBy，behavior为instant；如果没有内部滚动容器则回退window.scrollBy。当前页面为固定壳加内部列表，因此不能只滚动window。
- 被点击卡片不施加纵向FLIP位移，避免位置补偿后又被动画拉回旧位置；相邻卡片保留230ms平滑过渡。行组的真实测量仍按原帖子ID同步列位置、跨度与阅读观察器。
