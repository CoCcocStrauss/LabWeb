# 2026-11-23 共用理由库与互动内容比较：实现和验收

依据用户更新的 LabWeb_修改交接.md 实现。以下为本机完成阶段的过程记录；用户随后已执行增量SQL并授权正式发布，当前状态和外网QA见 [本轮发布记录](release-reasons-2026-11-23.md)。此前已上线的 v3 记录和流程保留。

## 新流程

新参与者采用问卷版本 `2026-11-23-reasons-v1`、本地 schemaVersion 4，存储键为 `labweb:session:v4:<编码后的UID>`。既有 v1／v2／v3 本地会话优先按原版本继续，旧题、原因数字ID、primary、计分含义和校验保留；不在中途加入新题，不把旧答案重新解释为核心题。

- 前测：核心观点题＋原有两道补充判断 → 把握 → 理由多选 → 全库最认可 → 全库最不认可 → 博物馆。
- 准备：完整前测在任务说明后台保存，失败可原页重试，逐条规则确认后才能继续；保留理解反馈与开始入口。
- 阅读：继续使用现有8／16／48条、90秒、满两次转发可手动结束、到时自动结束规则，保留现有瀑布流、标签与曝光定义。
- 后测：转发再认（无转发则记录不适用）→ 实际互动内容比较 → 核心观点题 → 把握 → 原有统一文字／语音解释 → 理由多选 → 全库最认可 → 全库最不认可 → 博物馆 → 最终保存。

AI与育儿补贴的核心题前后使用同一题干、命题、条件和五档选项，ID为 `core_attitude`。育儿补贴前测已明确每个孩子从出生每月2000元、直到18岁；后测不添加条件。博物馆维持三档、没有议题情境和标题。理由模块不会替代原有两道补充判断，也不会生成额外的信息流材料。

## 理由库与保存

两议题各36条实质理由（支持16、反对16、条件性4）逐字按交接表导入 `app/protocol/v4/data/reason-pools.json`，加上其他、整体感觉两项。混合随机顺序只在前测首次生成，后测复制同一份顺序；不按立场过滤，不预填答案、不提示保持一致。

多选没有三项上限；其他可与实质项并选，文字不设20字门槛；整体感觉与其他选项互斥。随后各用一页在全部36条实质理由中选最认可／最不认可，均包含未勾选理由，不限制最佳必须已选或最差必须未选；两者通常不同，另可分别回答暂时无法比较。补充项不参加实质理由排序。

`preReasons`／`postReasons` 分别保存池版本、全部38个candidateIds、38项文字和方向快照（补充项方向为supplement）、混合order、selectedIds、otherText、bestId／worstId、bestStatus／worstStatus、三页各自起止时间及模块完成时间。前后答案相互独立，比较不能做时保存unable和null ID，不编造选项。旧reasons／primary在新记录中为null，旧记录按原版本保留。

## 互动帖子比较

在再认回答完成后才生成并呈现。根据阅读行为依次折算仍点赞集合，与实际转发集合取并集并按postId去重，不使用再认答案推断实际转发，不截取固定8条。记录原始阅读顺序，展示顺序只随机一次并持久化。

展示原始全文、阅读时的昵称头像及实际单标签；允许收起／展开，保留已点赞／已转发标记，不提供修改原行为的操作。两项分别选支持最强和支持最弱，正常排序要求不同帖子；也可回答支持相近或都不能支持，分别记录similar_support／no_support且不伪造排序。单候选展示并记single_candidate，无需排序；无候选记no_interacted_posts并直接进入核心题。取消点赞历史仍留在行为中，但不误算仍点赞。

`interactionComparison`保存activeLikedIds、sharedIds、candidatePostIds、内容及作者标签快照、实际顺序、排序或特殊状态、起止时间、展开状态与事件、独立的reviewIntervals。复看区间按卡片有实际可见像素且页面在前台计时，隐藏时关闭，刷新后不累计离开时间；每秒、可见性变化及pagehide持久化，继续时结算。复看与正式阅读的reading_metrics严格分离。

服务端从本次合法材料、呈现的人设和最终行为重建候选，验证完整集合、原文、实际标签、顺序、比较答案及时间；拒绝未呈现／未互动的候选、伪造正文或标签、集合外的排序。原始标签仍有两类候选，同时保留实际显示类型与文字。

## 数据库与上线顺序

增量文件：[release-reasons-20261123.sql](../supabase/release-reasons-20261123.sql)。在已有v3迁移之后执行完整文件即可，不需重跑所有历史SQL。

增加experiment_sessions的pre_reasons、post_reasons、interaction_comparison三个JSON字段，以及save_experiment_pretest_v5、save_experiment_explanation_v5、submit_experiment_v5三个RPC。沿用原私有音频验证与事务，拒绝未完整保存的前测理由、尚未提前保存的解释和缺少新模块的最终提交。前测理由保存后不能被不同答案的重试覆盖；最终提交仍按载荷摘要幂等。

旧RPC不替换，anon／authenticated不获得新函数调用权限。SQL在本机PGlite通过，包含在旧v3记录已存在时迁移、重复执行迁移、旧记录不变、旧v3仍能完成、新模块保存及失败回滚。正式库尚未执行本文件，因此先完成迁移再发布新版网页；本轮没有向正式库写测试记录。

## 测量边界

前测理由展示构成共同信息接触，后测核心判断又发生在互动内容复看之后。因此整体变化反映本版程序的综合结果，不能宣称是纯90秒阅读效应。最弱支持不等于反对，不把理由更换或best／worst赋正负分后冒充连续态度。候选文案的可理解性、负担和作答时长仍需研究预测试，技术验证不等同量表验证。
